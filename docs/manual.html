在席ボード 使い方

みんなの「いま」を1枚で共有するボードです。やることは 自分のコマをタップする だけ。

1. 開く

  • ボードのURLを開く。スマホは「ホーム画面に追加」しておくとワンタップで開けます。
  • PC・タブレット・スマホ、どれで開いても同じ内容です。

2. 状態を変える

  • 自分の名前のコマを タップするたびに1つ進みます。
  • 順番: 在席 → 外出 → 退社 → 休み → 在宅勤務 → 出張 → 在席(一周して戻ります)。
  • 押した瞬間に色が変わり、数秒で全員の画面に反映されます。
在席外出退社 休み在宅勤務出張

3. 押し間違えたら

  • 押した直後に出る帯の 「戻す」 を押すと元に戻ります(8秒以内)。
  • 過ぎてしまったら、そのままタップを続けて一周させてください。

4. 外出・出張の行き先

  • 外出・出張にした直後の帯の 「行き先」、またはコマの 「＋行き先」 を押して入力します(例: 市役所、〇〇社)。
  • 行き先はコマに表示され、在席などに戻すと自動で消えます。

5. 2つの事務所を行き来する人

  • コマの左下に 「⇄ 拠点名」 のバッジがあります。押すと、いる場所がもう一方の事務所に切り替わり、その区画に移動します。
  • コマ本体のタップは状態の切替、バッジのタップは場所の切替です。
注意
  • このURLは 社外秘 です。知っている人は誰の状態でも変えられます。外部に送らないでください。
  • 自分以外のコマも押せます(代理で変えたいときに使えます)。間違えて押したら「戻す」。
  • 表示が古いと感じたら、画面を再読み込み(スマホは引っ張って更新)してください。
